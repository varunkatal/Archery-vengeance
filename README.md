# Archery Vengeance

A 2D browser archery game made with HTML, CSS, and JavaScript (Canvas).

**Play online:** https://varunkatal.github.io/Archery-vengeance/

## How to play

- Move the mouse (or drag your finger) to aim.
- Click (or lift your finger) to shoot.
- Hit the target to score points. Miss 3 times and the game is over.

## Run it on your computer

1. Open this folder in VS Code.
2. Double-click `index.html` to open it in your browser.
   Or, in the VS Code terminal, run `python3 -m http.server 8000` and go to http://localhost:8000.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript + Canvas API
